## 🎯 What This Project Is

This is 30 days of real work output.

Each day, I was given a business scenario, a dataset, and a question my manager needed answered. I had to profile the data, clean it, analyse it, and communicate findings in plain business language, the same workflow used by analysts at fintech companies across Africa and globally.

**The fictional company:** PalmPay Analytics is a fictional mobile money platform operating across Nigeria.

**The business questions I answered:** Transaction failure rates by channel, regional revenue breakdown, customer retention, fraud pattern detection, cohort analysis, churn prediction, and more.

## 🧠 Key Lessons Learned

*This section updates as the bootcamp progresses.*

- **Day 1:** Profiling data before analysis is not optional — it is the analysis. Five hidden problems in 50 rows would have made every downstream calculation wrong.
- **Day 2:** Excel COUNTIF is case-insensitive. =COUNTIF(F:F,"Success") also catches "SUCCESS" and "success". Clean your data anyway — other tools like Python are case-sensitive.
